# Rotate an array

Read two integers `n` and `k` (1 ≤ n ≤ 10^5, 0 ≤ k ≤ 10^9), then `n` integers
(−10^9 ≤ a_i ≤ 10^9). Rotate the array right by `k` positions: the number at index `i` moves to
index `(i + k) mod n`. Print the rotated array on one line, the numbers separated by single
spaces.

## Example

Input:

```
5 2
1 2 3 4 5
```

Output:

```
4 5 1 2 3
```

Time limit 1 second, memory limit 256 MB.
