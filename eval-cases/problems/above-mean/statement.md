# Above the mean

Read an integer `n` (1 ≤ n ≤ 2000), then `n` integers `a_1 … a_n` (−10^9 ≤ a_i ≤ 10^9),
separated by spaces or newlines. Print how many of them are strictly greater than the mean of
all `n` numbers.

## Example

Input:

```
4
1 2 3 10
```

Output:

```
1
```

The mean is 4, and only 10 is greater than it.

Time limit 1 second, memory limit 256 MB.
