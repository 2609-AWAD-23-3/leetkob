# Architecture decisions

Lưu quyết định kiến trúc có ảnh hưởng nhiều module hoặc checkpoint. Không tạo ADR chỉ để tăng số lượng tài liệu; overview/data-model đủ cho quyết định nhỏ.

Khi có quyết định cụ thể, tạo file NNNN-short-title.md và ghi:
- Trạng thái: đề xuất / chấp thuận / thay thế; không nhận chấp thuận khi chưa có xác nhận.
- Bối cảnh và yêu cầu/nguồn liên quan.
- Các phương án thực tế đã xem xét.
- Lựa chọn, lý do, hệ quả và giới hạn.
- Người ghi, reviewer và liên kết task/PR.

Khi thay đổi, giữ lý do và trỏ tới quyết định thay thế. Facts riêng LeeTKOB thuộc docs này; phương pháp lập plan/review dùng skill, không ghi quyết định stack của project vào skill dùng chung.

Quay lại [architecture overview](../overview.md) hoặc [plans](../../plans/README.md).
