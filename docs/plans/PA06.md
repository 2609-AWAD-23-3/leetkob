# PA06 — Kế hoạch final demo và vấn đáp cá nhân

**Sản phẩm:** LeeTKOB · **Nhóm:** 3 thành viên · **Thang điểm:** 100 mỗi thành viên · **Trọng số:** 15% môn học.

**Theo dõi:** milestone PA06 và Issues `[PA06][Txx]` ở bảng mục 3.

## 1. Mục tiêu

PA06 không xây thêm tính năng: build là bản `pa5` đã nộp ở [PA05](PA05.md). Mỗi thành viên nhận một điểm gồm:

- **Final build — 40 điểm chung:** B1 mười một feature F1–F11 trên running build (22), B2 build đã nộp với dữ liệu thật (4), B3 hai failure case do giám khảo chỉ định (6), B4 roles và ownership (4), B5 vượt brief (4).
- **Phần giải thích — 60 điểm riêng:** đọc code của mình, vì sao nhóm quyết định như vậy, làm sao biết nó hoạt động, feature LLM trên input cho trước.

Slot gồm: kiểm tra build (1 phút), main flow và các feature khác (8 phút), build checks (2 phút), câu hỏi (khoảng 4 phút mỗi thành viên).
