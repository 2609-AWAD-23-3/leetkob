## 1. Mục tiêu và bản final PA03

PA03 là lần đầu **toàn bộ pipeline chạy thật trên deployment public**: TA tạo lab có constraints, student nộp bài, code vào queue, worker riêng chấm trong sandbox, bài Accepted qua hard rules rồi model, verdict kèm evidence chỉ hiện ở review queue của TA. Plan chỉ nhắm **vừa đủ rubric PA03**, không làm sớm phần PA04/PA05.

### Bản final phải có

| Thành phần | Kết quả cần bàn giao |
| --- | --- |
| Luồng sản phẩm | Trên deployment, qua API hoặc màn hình của sản phẩm: TA tạo lab `sort-merge` (statement, tests, hai constraints + mức trừ); student nộp ba bài (tuân thủ, vi phạm, injection); bài chuyển queued → judged, student thấy kết quả chấm; review queue có verdict, dòng evidence và mức trừ cho từng bài × constraint; TA lớp khác bị chặn. |
| Queue và sandbox | Worker riêng; dừng worker → nộp → khởi động lại → đúng một bộ verdict được lưu. Compile + run trong sandbox đủ 9 minimums, mỗi minimum một bài tấn công chạy trong CI trên tag `pa3`. |
| Hard rules | Ban-list do code hiểu cú pháp quyết định; không dính trap; constraint đã quyết thì không gọi model, call log chứng minh. |
| Model | Model thật cho constraint semantic; prompt chỉ có statement, constraints, code đã bỏ comment và danh tính; output `pass`/`violation`/`unsure` + evidence; schema sai hoặc timeout → `unsure`, có test fake model không network. |
| Checker và eval | Một lệnh + Dockerfile, `MODEL_OFF=1`; dev set nguyên byte; ≥5 case riêng (≥1 `trap`, ≥1 `injection`); dev run thật đã commit (predictions + báo cáo `eval.mjs` + call log). |
| Hồ sơ và bản nộp | `PA3.md`, `AI-LOG.md`, `SELF_ASSESSMENT_REPORT.md`, README (model + chi phí lab 80 bài), video ≤5 phút, tag `pa3` đã push, ZIP có `.git` đúng tên, deployment giữ chạy tới khi có điểm PA04. |

**Không làm trong PA03:** ngưỡng eval, đủ 5 guardrails, cost cap theo lab, eval làm required check, lấy mẫu 10% pass, TA bắt buộc chỉ dòng khi chọn `violation` (PA04); publishing hoàn chỉnh cho student, appeals, real-time, logs/metrics/traces, load test (PA05); UI admin quản lý lớp, rate limit, gia hạn/nộp trễ. Quy tắc syllabus vẫn giữ: verdict không bao giờ đến student nếu chưa qua TA, output model luôn qua schema check và time limit.
